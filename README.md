# Librairie personnelle

Ouvrages, playbooks et cours conservés pour référence. Dépôt privé : la plupart
de ces contenus sont sous licence et n'ont pas vocation à être rediffusés.

## Contenu

| Type | Exemples |
| --- | --- |
| Livres | *Influence* (Cialdini) |
| Playbooks | `$100M Playbook`, `100M Leads` (Alex Hormozi) |
| Cours et notes | Supports LinkedIn, diagnostics |

## Règles du dépôt

- **Privé, et il le reste.** Aucune publication, aucune copie ailleurs.
- Les PDF sont versionnés tels quels : pas de réencodage, pas de compression.
- `_chapters.generated.json` est généré, ne pas l'éditer à la main.

## Avertissement

Ces fichiers restent la propriété de leurs auteurs et éditeurs. Ce dépôt est une
copie de travail personnelle, sans aucune intention de redistribution.
